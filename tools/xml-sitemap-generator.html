What Is an XML Sitemap?

An XML Sitemap is a file containing URLs that you want search engines to discover and crawl. It can be especially useful when a website has many pages, newly published content, or pages that may be harder for crawlers to discover through internal links.

This tool creates a standard sitemap structure with each URL, the current generation date, change frequency and priority values.

How to Use the XML Sitemap Generator

  1. Enter one complete website URL per line.
  2. Select an appropriate change frequency.
  3. Choose a priority value.
  4. Click Generate.
  5. Review the generated XML.
  6. Use Copy or Download to save the sitemap.
  7. Publish the file as sitemap.xml at your website's root URL.
  8. Optionally submit the sitemap URL through your search engine webmaster tools.

XML Sitemap Best Practices

  • Include canonical URLs that you want search engines to discover.
  • Do not intentionally include broken, redirected or duplicate URLs.
  • Keep the sitemap updated as your website changes.
  • Use accurate URL values and make sure the published sitemap is accessible.
  • For large sites, consider splitting URLs into multiple sitemap files and using a sitemap index when appropriate.
  • Remember that a sitemap helps discovery but does not guarantee indexing.

Change Frequency and Priority

Change frequency describes how often a URL is expected to change. Common values include daily, weekly and monthly.

Priority is a value from 0.0 to 1.0 indicating relative importance within the sitemap. Use values consistently rather than assigning 1.0 to every page without a reason.
